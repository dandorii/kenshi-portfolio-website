17/10/2026 Personal Archive // Visual Refinements DESIGN

Continued refining the About Me section and the visual identity of my personal website. I'm replacing the original profile emblem with a personal profile picture and planning to use a Persona 3 GIF for the hero artwork.

The goal is to make the site feel more personal while preserving its dark interface, cyan accents, and retro game-inspired atmosphere.

17/10/2026 YoruTerminal // Core Milestone PROJECT

Reached a major development milestone for YoruTerminal, a terminal-based cybersecurity learning simulator built with Python. Inspired by tactical interfaces and Japanese aesthetics, the project turns cybersecurity concepts into interactive, mission-based challenges.

The current build includes local account authentication, SQLite-based progress tracking, XP and ranks, and four standalone missions: Phishing Detective, Log Investigator, Security Puzzle Room, and Incident Response Simulator.

I also implemented a Rich-powered terminal interface, a mission history system, and a dedicated Windows launcher. The project reached 101 passing tests, marking an important step toward a stable first release.

MILESTONE: 101 TESTS PASSED // VERSION 1.0.0 PREPARATION

This project is helping me practice Python, authentication, database design, testing, and the process of turning an idea into a structured software application.

17/10/2026 Soundtrack Integration EXPERIMENT

Started integrating a Spotify track into the Now Playing panel. Instead of building a separate audio playback system, I'm using Spotify's embedded player so playback can be handled by Spotify.

I'm also refining the player presentation to match the website's archive-style interface. Embed compatibility and browser behavior are still being checked.

17/10/2026 Interface & Interaction Design FRONTEND

Continued working on the site's interactive details, including its boot sequence, live clock, interface sound controls, expandable update entries, and hidden interactions.

I'm learning how small JavaScript behaviors and thoughtful CSS styling can make a static website feel more like a personal digital environment.

14/10/2026 PhishGuard // Deployment Milestone CYBERSECURITY

Continued developing PhishGuard, my phishing URL and email analysis web application built with Python, Flask, and SQLite. The project includes analysis tools, risk assessment, and an analysis history.

I also worked on responsive navigation and continued exploring deployment, application security, and the process of maintaining a publicly accessible web project.
